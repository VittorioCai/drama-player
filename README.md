# 美剧播放器

在 iPad 上看自己导入的美剧。记住播放位置，带中英字幕、单句循环、字幕列表。视频只存在 iPad 本地。

## 在 iPad 上安装

1. 用 Safari 打开播放器的网址。
2. 点分享按钮 → 「添加到主屏幕」。之后从主屏幕图标打开，全屏、离线可用。

## 导入

1. 把视频（mp4 / m4v / mov）和字幕（srt / vtt / ass）放进「文件」App：Mac 上 AirDrop 发过去，或放进 iCloud 云盘。
2. 在播放器里点「导入视频和字幕」，多选，可以一次选一整季。
3. 字幕和视频同名，或文件名里都有 S01E05 这样的集数，会自动配对。英文字幕和中文字幕分开的，一起选上会自动合并成双语。

导入时会把视频复制进播放器，导入过程中不要离开页面或锁屏。复制完「文件」里的原文件可以删掉。

## 播放时

| 操作 | 触屏 | 键盘 |
|---|---|---|
| 显示 / 隐藏控制栏 | 轻点画面 | |
| 播放 / 暂停 | 中间按钮 | 空格、K |
| 后退 / 前进 | 双击左 / 右半屏（连点可以多跳） | ← → （5 秒） |
| 拖进度 | 在画面上左右拖，或拖进度条 | |
| 上一句 / 下一句 | ⏮ ⏭ | A / D |
| 单句循环 | 「单句循环」 | R |
| 字幕：英文 / 双语 / 中文 / 关闭 | 「字幕」 | S |
| 遮挡字幕（点模糊的字幕可以看） | 「遮挡字幕」 | B |
| 字幕列表 | 「字幕列表」 | L |
| 速度 | 「1×」 | [ ] |

右上角的设置里可以改字幕大小、字幕偏移（每集单独记住）、双击跳几秒、播完是否自动放下一集、换字幕文件，以及「遮住视频里自带的字幕」：视频画面里已经压了字幕时打开，按剧记住。

## mkv 转换（在 Mac 上）

iPad 播不了 mkv。用自带脚本转成 mp4，视频不重新编码，一集几秒钟：

```
tools/convert-mkv.sh ~/Desktop/shadowing/摩登家庭S02
```

视频里有文字字幕的话，会一起抽成同名 .srt。

## 开发

- `index.html` 是全部代码；`sw.js` 离线缓存；`manifest.webmanifest` 和图标用于添加到主屏幕。无依赖、无构建。
- 本地预览：`python3 -m http.server 8766`，打开 http://localhost:8766 。`test-media/` 放测试视频，不提交。
- 改了 `index.html` 后，把 `sw.js` 里的 `CACHE` 版本号加一，iPad 上才会尽快更新。
- 图标：`python3 tools/make_icons.py`。
- 设计和取舍见 `开发文档.md`。
